Upload photos directly to GitHub. They appear on the website instantly.

How to update a photo
  1. Click "Choose Photo" on any slot below
  2. Select your photo from your phone or computer
  3. Click "Upload to GitHub"
  4. Enter your GitHub Personal Access Token when prompted
  5. Done! Your website updates in 30 seconds ✅
🔑 Need a GitHub token? Go to github.com/settings/tokens/new → Note: "Anvi Website" → Expiration: No expiration → tick repo → Generate token → copy it
